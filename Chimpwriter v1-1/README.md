# Chimpwriter

Local-only transcription GUI for Windows using PySide6, faster-whisper, ffmpeg, and yt-dlp.

## Quick start

1. Run setup to create a venv and install dependencies:

```powershell
.\scripts\setup.ps1
```

2. Ensure ffmpeg is in PATH.

3. Run the app:

```powershell
.\Chimpwriter.bat
```

The app starts in the tray. Click the tray icon to show the Quick Drop Zone.
